Frequently asked questions

Everything you need to know about adding DotWidget widgets to Notion.

How do I add a widget to Notion?

Open the Studio, pick a widget and style it. Click Embed, copy the link, paste it into your Notion page and choose “Create embed”. Your colours, fonts and text are saved inside the link.

Are DotWidget widgets free?

Yes. Every widget is free to use, needs no account or sign-up, and the project is MIT licensed.

Which widgets are included?

Calendar, flip clock, stopwatch, countdown, Pomodoro timer, habit tracker, calculator, quote card, time progress bars and a GitHub profile card.

Can I show my GitHub profile in Notion?

Yes. Enter your GitHub username in the GitHub Profile widget and your name, bio, avatar, followers, repositories, stars and top language load automatically.

Can I get a random quote widget?

Yes. The Quote widget has a Random quote button, and it can also show a fresh random quote every time your page loads.

Do the widgets work outside Notion?

Yes. Each widget is a plain HTML, CSS and JavaScript page, so you can embed it with an iframe on any website or tool that supports embeds.
